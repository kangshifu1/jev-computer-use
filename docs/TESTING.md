## 复现

在安全的本地环境设置 `TYPESAFE_API_KEY` 后运行：

```sh
npm ci
npx playwright install chromium
node scripts/capture-evidence.mjs
```

脚本还会测试本机已安装的 Chrome。可通过 `JEV_SKILL_DIR` 指定独立安装的 Skill 目录；
不设置时测试当前工作树，并在记录中明确区别。脚本会调用真实 API、更新合成截图和证据文件。
默认 CI 不运行付费 API 测试。
